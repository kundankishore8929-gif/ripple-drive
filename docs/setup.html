Ripple Drive

Set up Ripple Drive on your Macon your PC

Your whole Google Drive as a disk in Finder. Files stream as you open them, so they barely use any space on your Mac. You do this once; it takes about 30 minutes.

Your whole Google Drive as a drive in File Explorer. Files stream as you open them, so they barely use any space on your PC. You do this once; it takes about 30 minutes.

Which computer are you setting up?

Steps marked Mac + Windows are the same on both. Steps marked Different on Mac and Windows show the version for the computer you picked.

Do this on your computer, not your phone. If you opened this from Instagram, send the link to your computer (AirDrop, WhatsApp or email) and follow along there.

The Windows version is in beta. It passes automatic tests on GitHub's Windows machines but hasn't been used on many real PCs yet. If something doesn't work, open an issue with what you saw.

Step by step

0 of 10 done
  1. 1

    Turn on 2-Step Verification

    Mac + Windows2 min

    Google Cloud only opens for accounts with it switched on.

    1. Open myaccount.google.com/security.
    2. Under “How you sign in to Google”, turn on 2-Step Verification. Skip this if it’s already on.
  2. 2

    Create a Google Cloud project

    Mac + Windows2 min

    This gives Ripple Drive its own free key to your Drive, separate from everyone else’s.

    1. Open console.cloud.google.com and accept the terms if asked.
    2. Click the project picker at the top › New project.
    3. Name it Ripple Drive, click Create, then select it in the picker.
  3. 3

    Turn on the Google Drive API

    Mac + Windows1 min
    1. Open Google Drive API (with your Ripple Drive project selected).
    2. Click Enable.
  4. 4

    Set up the sign-in screen

    Mac + Windows4 min
    1. Open Google Auth Platform and click Get started.
    2. App name Ripple Drive, support email: yours. Audience: External. Contact email: yours. Tick the agreement, then Create.
    3. Go to Audience › Test users › Add users, add your own Gmail address, Save.
    4. Go to Data access › Add or remove scopes. Under “Manually add scopes”, paste this, click Add to table, then Update and Save:
    https://www.googleapis.com/auth/drive
  5. 5

    Create your client ID

    Mac + Windows2 min
    1. Go to Clients › Create client.
    2. Application type: Desktop app. Name: Ripple Drive. Click Create.
    3. Copy the Client ID and the Client secret into a note, and click Download JSON as a backup. Google may not show the secret again.

    Keep the secret to yourself. Don’t paste it in a chat, a comment or a DM. You only paste it into the installer in step 8 (TerminalPowerShell).

  6. 6

    Download Ripple Drive

    Mac + Windows1 min
    1. Open github.com/kundankishore8929-gif/ripple-drive.
    2. Click the green Code button › Download ZIP.
    3. Open the ZIP in Downloads. You get a folder called ripple-drive-main.
    4. In Downloads, right-click the ZIP › Extract All › Extract.
  7. 7

    Install Homebrew, if you don’t have it

    Open PowerShell in the folder

    Different on Mac and Windows5 min1 min

    Homebrew installs fuse-t, the piece that lets macOS show your Drive as a disk.

    1. Open Terminal (press ⌘ Space, type “Terminal”, press Return).
    2. Check whether you have it. If you see a version number, skip to step 8.
    brew --version
    1. If it says “command not found”, paste this and follow what it says:
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    1. When it finishes, it prints “Next steps” with two or three commands. Copy and run those too.

    No Homebrew on Windows: the installer fetches everything it needs by itself.

    1. Open the folder you just extracted. Keep opening ripple-drive-main until you see install.sh and a folder called windows.
    2. Click the address bar at the top of the window, type powershell and press Enter.
    3. A blue or black PowerShell window opens, already in the right folder.
  8. 8

    Run the installer

    Different on Mac and Windows5–10 min

    In Terminal, run these two lines one after the other:

    cd ~/Downloads/ripple-drive-main
    zsh install.sh

    Along the way:

    • If a window asks to install Command Line Tools, click Install. When it’s done, run zsh install.sh again.
    • If macOS asks whether Terminal may access Downloads, click Allow.
    • Type your Mac password when asked. It stays invisible while you type.
    • Paste your Client ID and press Return, then the Client secret and Return. The secret stays hidden.

    In PowerShell, paste this line and press Enter:

    powershell -ExecutionPolicy Bypass -File windows\install.ps1

    Along the way:

    • When Windows asks “Do you want to allow this app to make changes?” for WinFsp, click Yes. It’s what lets Windows show your Drive as a drive.
    • If this PC has no Python yet, the installer adds it for you. Nothing to click.
    • Paste your Client ID and press Enter, then the Client secret and Enter. The secret stays hidden. To paste in PowerShell, right-click or press Ctrl V.
  9. 9

    Sign in with Google

    Mac + Windows1 min
    1. Your browser opens Google’s sign-in. Pick your account.
    2. On “Google hasn’t verified this app”, click Advanced › Go to Ripple Drive. It’s the app you just made, so this is expected.
    3. Tick the box to let Ripple Drive see and manage your Drive files, then click Continue.
    4. Back in TerminalPowerShell you’ll see “Signed in.”
  10. 10

    Turn on fuse-t

    Find your drive

    Different on Mac and Windows1 min
    1. Open System Settings › General › Login Items & Extensions.
    2. Under Extensions, choose By Category › File System Extensions and switch fuse-t on.
    3. Click the Ripple icon in the menu bar › Reconnect Drive.

    Nothing to switch on: WinFsp works as soon as it’s installed.

    1. Open File Explorer › This PC. Ripple Drive (R:) is there, with My Drive and Shared with me inside.
    2. The Ripple icon sits by the clock. If you don’t see it, click the ^ arrow and drag the icon onto the taskbar so it stays visible.
    3. If the drive isn’t there after a minute, click the Ripple icon › Reconnect Drive.

You’re set. Here’s how to use it.

Open any file
Ripple Drive is in Finder’s sidebar, with My Drive and Shared with me. Open files as usual.
Upload big files
Right-click a file › Services › Upload to Ripple Drive, or drag it to the Ripple icon in the menu bar.
Upload and free space
Right-click › Services › Move to Ripple Drive. The original goes to the Trash once Drive confirms the copy.
Find anything
Press ⌃⌥F from any app and type a file name.
Open any file
Ripple Drive (R:) is in File Explorer under This PC, with My Drive and Shared with me. Open files as usual.
Upload big files
Right-click a file › Ripple Drive › Upload to Ripple Drive (on Windows 11, first click Show more options). Or open the Ripple icon › Upload Window and drop files on it.
Upload and free space
Right-click › Ripple Drive › Move to Ripple Drive. The original goes to the Recycle Bin once Drive confirms the copy.
Find anything
Press CtrlAltF from any app and type a file name. CtrlShiftC copies its share link.

If something goes wrong

“Google Cloud access blocked”

Your account needs 2-Step Verification (step 1). Turn it on, wait a few minutes, then refresh.

“Access blocked: Ripple Drive has not completed the Google verification process”

Your Gmail isn’t a test user yet. Add it under Google Auth Platform › Audience › Test users (step 4).

The Ripple icon turned red

Google ends the sign-in every 7 days while your Google app is in “Testing”. Click the icon › Sign In Again (1 minute). To stop this for good, see Stop the weekly sign-in.

Ripple Drive isn’t in Finder

Check that fuse-t is on (step 10), then click the Ripple icon › Reconnect Drive.

Ripple Drive (R:) isn’t in File Explorer

Click the Ripple icon by the clock › Reconnect Drive and wait 10 seconds. If the icon says “Not signed in”, choose Sign In. If it still doesn’t show, open the icon › Show Logs and look at mount.log.

A file I just added says “No such file”

Click the Ripple icon › Reconnect Drive. It takes about 10 seconds.

The installer says fuse-t is missing

Install it with Homebrew, then run zsh install.sh again:

brew install macos-fuse-t/homebrew-cask/fuse-t
“Running scripts is disabled on this system”

Use the exact line from step 8. The -ExecutionPolicy Bypass part lets this one installer run without changing any Windows setting.

WinFsp didn’t install

Download it from winfsp.dev/rel, install it, then run the installer line from step 8 again.

The right-click Ripple Drive menu is missing

On Windows 11, right-click › Show more options first (or hold Shift while right-clicking). The Ripple icon › Upload Window works too.

Drive letter R: is already used

Pick another free letter by running the installer again with it, for example:

powershell -ExecutionPolicy Bypass -File windows\install.ps1 -Drive S:
Remove Ripple Drive

From the ripple-drive-main folder in Terminal. Your files in Google Drive are not touched:

zsh uninstall.sh

From PowerShell in the ripple-drive-main folder (step 7). Your files in Google Drive are not touched:

powershell -ExecutionPolicy Bypass -File windows\uninstall.ps1

Your files go only between your computer and your own Google account. Ripple Drive has no server and no sign-up, and nobody else sees your key.
